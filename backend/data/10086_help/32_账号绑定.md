帐号绑定提供用户互联网帐号和手机号之间的绑定或者解绑服务；用户可使用该服务绑定自己的手机号，享受更优质的中国移动网上商城服务。

# 一、互联网帐号绑定手机号码

互联网用户绑定手机号过程如下：

1、互联网用户登录成功后访问安全助手点击右上角帐号绑定内的绑定/解绑（如下图3-53），进入查看帐号绑定页面（如图3-54）；

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/1.jpg__58.jpg)

图 3-53 安全助手页面

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/2.jpg__58.jpg)

图3-54帐号绑定页面

2、若用户该手机号未被任何邮箱绑定，将会显示该手机号未绑定任何邮箱，用户可点击新增绑定按钮（如图3-55），进行号码绑定。

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/3.jpg__58.jpg)

图3-55 账户绑定页面（未绑定任何手机号）

3、用户按照要求，输入需要绑定的手机号信息，点击保存按钮（如图3-56）；即可进行该号码绑定，绑定成功后在已绑定号码列表中将会显示被绑定的号码，如下图3-57。用户可继续绑定号码，最多可绑定5个手机号码。

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/4.jpg__58.jpg)

图3-56 账户绑定页面

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/5.jpg__58.jpg)

图3-57帐号绑定页面（已绑定手机号）

# 二、互联网帐号解绑手机号

当用户对某一手机号弃用或者其他原因需要解绑手机号时，可对自己的某一绑定手机号进行解绑，解绑流程如下：

1、用户在帐号绑定页面，选择需要解绑的手机号码，点击解绑，如下图3-58

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/6.jpg__58.jpg)

图3-58帐号绑定页面

2、在弹出的操作确认页面点击确认，如下图3-59红色边框内的按钮，即可解除该手机号码的绑定；

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/7.jpg__58.jpg)

图3-59 解绑手机号码

# 三、手机帐号解绑互联网帐号

若互联网帐号进行号码绑定时，发现手机号已经被其他互联网帐号绑定，而自己却不知道手机号被哪个帐号绑定，此时，可以用手机号逆向解绑自己的互联网绑定帐号。

相关操作步骤如下：

1、手机用户登录成功后访问安全助手点击右上角帐号绑定内的绑定/解绑（如下图3-60），进入查看帐号绑定页面（如图3-61）；

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/8.jpg__58.jpg)

图3-60安全助手页面

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/9.jpg__58.jpg)

图3-61 帐号绑定页面

2、在已绑定帐号位置，可以看到该号码绑定的邮箱帐号信息。点击解绑按钮，如下图3-62

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/10.jpg__58.jpg)

图3-62进行帐号解绑

3、在弹出操作确认按钮。点击确认，即可解除该号码与邮箱帐号的绑定。

![原网页图片](https://img0.shop.10086.cn/www/help/css/zhbd/11.jpg__58.jpg)

图3-63 手机号解绑确认页面
