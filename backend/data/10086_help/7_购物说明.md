# 一、浏览商品

1、您可以在商城的搜索栏中直接搜索想购买的手机名称

![原网页图片](https://img0.shop.10086.cn/www/help/css/gmlj/01.jpg__114.jpg)

2、也可以在商城首页的广告中挑选喜爱的手机型号

![原网页图片](https://img0.shop.10086.cn/www/help/css/gmlj/02.jpg__114.jpg)

3、还可以从首页左侧导航栏进入手机类产品列表页，在此页面内挑选您喜爱的手机

![原网页图片](https://img0.shop.10086.cn/www/help/css/gmlj/03.jpg__114.jpg)

4、在手机类产品的列表页中挑选喜爱的手机，进入到手机详细信息页面查看

![原网页图片](https://img0.shop.10086.cn/www/help/css/gmlj/04.jpg__114.jpg)

# 二、购买商品

在手机类产品的列表页，您可以根据自身需要，选择喜欢的颜色、适用的手机容量。在移动商城购物时，您可以一次购买多个商品，并对临时放置的商品进行增加删除，修改数量等操作，确认后再到移动商城收银台进行结账。

在商品详情页面，选择“加入购物车”。

![原网页图片](https://img1.shop.10086.cn/goods/t6ta69dnqs89ft5v_940x7200)

提示“商品已成功加入到购物车”，目前可以加入购物车的商品有裸机和配件。

![原网页图片](https://img1.shop.10086.cn/goods/t6ta69zywz59fvrb_940x7200)

点击“返回”链接，您可以返回到刚才添加的商品详情页面。点击“去购物车结算”按钮，则直接进入到购物车页面。

![原网页图片](https://img1.shop.10086.cn/goods/t6ta6dgn4aq9fd25_940x7200)

在购物车页面，您可以对多个商品进行删除，修改数量等操作。如果已经登录，点击“去结算”，则进入“填写核对订单信息”页面。
