# 移动商城部分销售的商品，支持货到付款服务

一、在购物时，请留意商品信息中的支付方式，若表明“支持货到付款”，则表示购买该商品时，您可以选择货到后再支付商品款项

![原网页图片](https://img0.shop.10086.cn/www/help/css/hdfk/01.jpg__52.jpg)

二、填写订单信息时，在支付方式一栏中选择“货到付款”，点击提交订单，完成订单的提交

![原网页图片](https://img0.shop.10086.cn/www/help/css/hdfk/02.jpg__87.jpg)

三、购买的商品送到时，请准备好货款，一次性付清
