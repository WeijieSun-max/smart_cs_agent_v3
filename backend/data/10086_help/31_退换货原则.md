# 一、终端类商品退换货原则

1、质量问题退货：如所售商品售出之日（以实际客户签收日期为准）起7日内发生符合国家三包规定的功能性故障或商品质量问题，并经由生产厂家指定或特约售后服务中心检测确认出据检测报告的产品，以及经移动商城售后确认属于质量问题的，可以办理退货。客户退回商品还必须包含商品的外包装、说明书、保修卡、发票、配件、赠品等之前收到的所有商品。

合约类商品以及其他特殊商品，退换货方式以商品销售详情页为准。

2、质量问题换货：如所售商品售出之日（以实际客户签收日期为准）起15日内发生性能故障，要求换新，客户可就近至厂家授权网点进行处理，经检测符合换货条件，客户可凭发票、保修卡、检测报告等凭证享受换货服务。

3、以下情况不予办理退换货：

1) 任何非本商城出售的商品（序列号不符）；

2) 过保商品（超过三包保修期的商品）；

3) 未经授权的维修、误用、碰撞、疏忽、滥用、进液、事故、改动、不正确的安装所造成的商品质量问题，或撕毁、涂改标贴、机器序号、防伪标记；

4) 商品的外包装损坏/丢失，附件（需要和主商品一起退换）、说明书不完整，发票缺失或涂改；

5) 商品的赠品无法退还或者退还后影响正常使用时，无法办理退货。

6) 非商品质量问题，且商品已使用或商品包装已打开，影响商品二次销售的，不予办理退货。

# 二、终端类商品换新及保修服务

1、凭购机发票/协议单、保卡、串码贴、质保转印章，终端类商品均可以享受生产厂家的免费换新及全国一年联保服务，客户自行联系厂家当地授权维修点处理。

2、配件保修不包含在内，配件按照厂家规定保修。如特殊型号厂家有特殊保修时间，则按对应的特殊时间执行。

3、如人为问题造成的非保内维修，请客户直接在厂家当地授权维修点自费维修。

# 三、套卡类商品退换货原则

1、退货

套卡属于特殊商品，客户签收后，一律不接受退货。

2、换货

因套卡质量问题，导致客户无法正常使用sim卡的，客户可凭身份证至就近营业厅办理换卡。
