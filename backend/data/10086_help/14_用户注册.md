# 用户注册

为方便用户更好的体验中国移动各项服务，中国移动统一认证服务支持用户使用邮箱帐号（互联网帐号）登录，提供用户的邮箱帐号（互联网帐号）注册功能；在使用邮箱注册一个互联网通行证后，即可使用互联网账户登录体验中国移动各项服务。

邮箱帐号（互联网帐号）注册步骤如下：

一、用户访问统一认证登录页面，如下图

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/01.jpg__58.jpg)

图1-1 统一认证登录页面

二、点击登录页面‘注册’按钮，如下图1-2红色框内按钮，进入邮箱注册页面，如下图1-3

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/02.jpg__58.jpg)

图1-2 统一认证登录页面

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/03.jpg__58.jpg)

图1-3邮箱注册页面

三、在注册页面输入注册邮箱号、密码、重复密码、正确验证码，点击‘同意以上条款并注册’按钮，如下图1-4，注册成功后跳转成功页面，如下图1-5

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/04.jpg__58.jpg)

图1-4邮箱注册页面

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/05.jpg__58.jpg)

图 1-5 注册成功页面

四、用户注册完成后点击去邮箱激活，按照邮件提示激活邮件后系统会提示用户邮件激活成功（如下图1-6），即可使用该注册邮箱进行登录服务。

![原网页图片](https://img0.shop.10086.cn/www/help/css/reg/06.jpg__58.jpg)

1-6邮箱激活成功页面
